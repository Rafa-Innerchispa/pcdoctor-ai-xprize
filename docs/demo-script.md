# Three-minute demo script

Target duration: 2:50. All screens must visibly identify synthetic versus
production evidence.

## 0:00–0:20 — Problem

Show a real-world request arriving as text/audio/photos. Explain that small
service businesses lose revenue because intent, follow-up, scope, and billable
work remain in WhatsApp and spreadsheets.

## 0:20–1:10 — Agent decision

Show FieldSpark:

- interpreting the request with Gemini;
- selecting the tenant playbook;
- classifying service and urgency;
- identifying missing information;
- proposing a next best action;
- creating an audit event with model and request reference.

## 1:10–1:50 — Human control

Show the approval inbox. Edit or approve the draft. Emphasize that FieldSpark
operates the routine decision process while people control price, commitments,
customer messages, and invoices.

## 1:50–2:25 — Two businesses, one product

Switch from the photography-studio continuity view to IAPRO's 18-service
consulting intake. Show a common agent platform and distinct playbooks.

## 2:25–2:45 — Business evidence

Show production-labelled Gemini event, Cloud Run revision, consented customer
usage, revenue/cost P&L, and redacted invoice/payment evidence. Use only real
evidence.

## 2:45–2:58 — Impact

FieldSpark helps small businesses turn operational attention into a repeatable
system, preserving customer relationships and capturing earned revenue.

## Shot checklist

- [ ] legible model and request reference
- [ ] production vs synthetic labels
- [ ] no secrets or customer PII
- [ ] both playbooks
- [ ] approval action
- [ ] P&L and real evidence
- [ ] public video under the official duration
