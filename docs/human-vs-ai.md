# Human vs AI

| Decision | AI | Human |
|---|---:|---:|
| classify request and service family | primary | exception review |
| extract missing information | primary | exception review |
| prioritize routine opportunities | primary | oversight |
| propose next best action | primary | approve external effect |
| create inspection/discovery checklist | primary | technical validation |
| draft scope and proposal | primary | legal/commercial validation |
| set or change price | no | mandatory |
| send a campaign or customer message | prepare only | mandatory in Phase 1 |
| issue Ecuadorian electronic invoice | no | mandatory |
| record confirmed payment | assist | verify source evidence |
| publish customer evidence | redact/prepare | mandatory consent and review |

The submission must demonstrate material AI decisions without falsely claiming
that business-critical legal or financial acts are autonomous.
